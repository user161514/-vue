## 排查：点击"编辑"后输入框文字不显示

**根因**：后端 `GET /dept2/{id}` 返回的 `data` 是**数组**（长度 1），不是单个对象：

```json
{"code":200,"msg":"success","data":[{"id":null,"name":"文泽宏","gender":null,...}]}
```

原代码 `dept.value = res.data` 把整个数组赋给了 `dept`，
模板 `v-model="dept.name"` 取数组的 `name` → `undefined` → 输入框空白。
与 Vue  reactivity 无关，纯粹是数据形状不匹配。

**修复**（`src/view/dept/index.vue` 的 `edit`）：
- `Array.isArray(res.data) ? res.data[0] : res.data` 兼容两种形状
- 空结果时 `ElMessage.warning` 并 return
- 用 `{ name: row.name ?? '' }` 造新对象，不与表格行共用引用
- 顺带给 `addDept` 加 `dept.value = { name: '' }` + `clearValidate()`，
  否则新增时会带上一次编辑的残留值和红字校验提示

## 本项目后端接口备忘（Apifox mock，localhost:8080）

| 接口 | 用途 | 返回 data 形状 |
|---|---|---|
| `GET /dept1` | 部门列表 | 数组 |
| `GET /dept2/{id}` | 查单条（回填表单） | **数组，长度 1**（易踩坑） |
| `POST /dept?name=x` | 新增 | — |

请求层 `src/utils/request.js` 的响应拦截器已 `return response.data`，
所以业务里拿到的 `res` 就是后端 body 本身，不用再 `.data.data`。

代理：`vite.config.js` 里 `/api` → `http://localhost:8080/`，并 rewrite 掉 `/api` 前缀。
