# 2026-10-03 工作日志

## Vue Playground(Element Plus 练习环境)

用户要在 `https://play.vuejs.org/` 上练习 Element Plus,让我把环境配好并用 Edge 打开。

**关键发现**:
- 用户那个 Playground 的 `import-map.json` **早就配好了**,依赖齐全:
  `element-plus@2.8.8`(jsdelivr 的 `index.full.min.mjs`)、`@element-plus/icons-vue@2.3.1`、`axios@1.6.8`、`vue`。
- **真正缺的是样式表**。import-map 只管 JS 模块,不含 CSS;必须在 `App.vue` 的 `<style>` 里写
  `@import url("https://cdn.jsdelivr.net/npm/element-plus@2.8.8/dist/index.css");`
  否则组件能渲染但没有外观(按钮是原生样式),看起来像"没配好"。
- `App.vue` 原本是空的。

**Playground 的机制(重要)**:
- 整个项目状态(各文件内容)被 **zlib 压缩 + base64 后编码在 URL 的 `#` 后面**。
  解码:`zlib.decompress(base64.b64decode(hash))` → JSON,形如
  `{"App.vue": "...", "import-map.json": "...", "tsconfig.json": "...", "_tsVersion": "6.0.3"}`。
  编码:`base64.b64encode(zlib.compress(json, 9))`(必须用标准 base64 字母表,不是 URL-safe)。
- 所以**在这个站点上"改配置"必然导致 URL hash 变化**——改内容 = 换地址,这是站点机制,不是另换网站。
- 项目状态也会存 localStorage,但带 hash 打开时以 hash 优先。

**本机环境限制(踩坑)**:
- `agent-browser` 自动化浏览器**打不开 play.vuejs.org**(页面渲染为空白,body innerText 为空),
  在这个无头环境里该站点加载不出来,不要再在这条路上浪费时间。
- 启动 Edge(`Start-Process msedge.exe`)会被沙箱拦,报
  "Command blocked for security: Start-Process ... bypasses PowerShell command validation",
  需要 `dangerouslyDisableSandbox: true` 让用户手动批准。
- PowerShell 调用 `npm` 也会被拦,但 Bash 调 npm 可以。
